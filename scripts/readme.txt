Он берёт файл зданий GlobalBuildingAtlas LoD1 и карту высот, и для каждого здания записывает отметку земли в той точке, где оно стоит.

Высота здания в колонке height не меняется. Добавляются две колонки:

ground_elevation — высота рельефа в центре контура, в метрах
roof_elevation — рельеф плюс высота здания
Z вершин контура становится равным ground_elevation, так что низ блока садится на рельеф. Если здание вне карты или в пикселе без данных, отметки остаются пустыми, а контур остаётся плоским. Система координат файла зданий не меняется: точки только переводятся в систему координат DEM для выборки.



Результат может быть .parquet, .geojson или .gpkg. Если высоты в DEM записаны в футах, добавь --dem-to-meters 0.3048. Если ни одно здание не попало на карту, скрипт завершается с ошибкой.


python scripts/add_ground_elevation.py buildings.parquet dem.tif -o buildings-with-ground.parquet




pip install -r scripts/requirements.txt
python scripts/gml_to_glb.py scripts/London.gml -o public/london/from-gml.glb

Файл может быть большим: этот GML на 2,1 ГБ собрался примерно за 5 минут в модель на 300 МБ. Координаты остаются как в GML и только сдвигаются к центру. Если в файле есть TIN-рельеф, плоские объекты сажаются на него. Объём с ровным низом, например дом, поднимается целиком, крыша остаётся плоской. Контур с measuredHeight становится блоком от земли до этой высоты. Чтобы оставить геометрию как в файле, добавь --no-drape.
